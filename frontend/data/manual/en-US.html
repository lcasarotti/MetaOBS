1. What MetaOBS is

MetaOBS is a version of OBS Studio designed for screen reader users. It does everything OBS Studio does (streaming, recording, scenes, sources, filters, plugins) and adds an Accessible Mode: a main window built from standard lists, buttons and menus, fully usable from the keyboard and tested with NVDA.

MetaOBS also:

  • announces through your screen reader when streams and recordings start and stop, scene changes, errors and stream quality warnings, even when its window is not in the foreground;
  • lets you move, resize and crop sources from the keyboard, and describes their position;
  • tells you whether your face is well framed by the webcam;
  • supports Stream Deck and MIDI controllers directly, without inaccessible third-party apps.

This manual covers the features that MetaOBS adds. For general OBS concepts (scenes, sources, encoders, output settings), see the OBS Studio documentation at obsproject.com/kb.

2. Installation and updates

Installing

Download the installer from the MetaOBS releases page on GitHub (github.com/lcasarotti/MetaOBS/releases) and run it. It first asks whether to install MetaOBS for you only (no administrator rights needed) or for all users of the computer. If needed, it also installs the Microsoft Visual C++ libraries.

MetaOBS installs into its own folder and can sit alongside OBS Studio. However, MetaOBS and OBS Studio share the same configuration (scenes, profiles, settings, plugins installed for your user), stored in %APPDATA%\obs-studio. Changes made in one show up in the other. Don't run them at the same time.

Instead of the installer you can use the zip archive: extract it to a folder and run bin\64bit\obs64.exe.

Updates

MetaOBS checks for updates from Help, Check For Updates, and at startup if that option is turned on in the General settings. When it finds a new version, it downloads it, verifies it, closes, installs the update and restarts. If you are streaming or recording, it asks before closing. At the next start it tells you which version it was updated to, or why the update failed.

3. Getting started

MetaOBS opens directly in Accessible Mode. The window is called "MetaOBS", followed by the version number and "Accessible Mode".

On first start, OBS offers the Auto-Configuration Wizard, which picks the resolution, frame rate and quality for streaming or recording. You can run it again at any time from the Tools menu.

A typical path to your first recording:

  1. The Scenes panel already contains a scene. Press Ctrl+2 to go to the Sources panel.
  2. Open the Source menu (Alt+O) and choose Add Source.... For example, choose "Video Capture Device" for your webcam, or "Display Capture".
  3. Name the source and confirm. The properties dialog opens, where you choose the device.
  4. Press Ctrl+3 to check in the Audio panel that your microphone and desktop audio are active.
  5. Press Ctrl+4 to move to the Controls panel, and press Start Recording. MetaOBS announces "Recording started".

Recordings are saved to the folder set in Settings, Output (usually your Videos folder).

Switching to the standard interface

Ctrl+Shift+A, or the View menu, switches between Accessible Mode and the standard OBS interface. The standard interface is mainly for sighted users. To stop starting in Accessible Mode, turn off "Start MetaOBS in Accessible Mode" in Settings, Accessibility.

When MetaOBS is minimized to the notification area, its icon's menu has an Accessible Mode item.

Each panel has its own menu in the menu bar (Scene, Source, Audio, Controls, Status), with the same items as its context menu. Open the context menu with the Applications key or Shift+F10. Menus show each item's shortcut.

The other menus are the usual OBS ones: File (with Settings), Edit (Undo and Redo), View, Profile, Scene Collection, Tools and Help. The Help menu has this manual, which also opens in your browser with F1 from any MetaOBS window. The View menu also has the command palette, plugin docks, projectors (preview, program, multiview) and Screenshot Output.

5. Scenes panel

Each scene in the list says whether it is "live" (the scene being streamed or recorded) or, in Studio Mode, "preview".

  • Enter switches to the selected scene. In Studio Mode it puts the scene in the preview.
  • Ctrl+Enter sends the selected scene straight to program with the current transition, even in Studio Mode.
  • F2 renames, Delete removes, Ctrl+D duplicates.
  • Alt+Up Arrow and Alt+Down Arrow move the scene in the list; Alt+Home and Alt+End move it to the top or bottom.

The Scene menu also has: Add Scene, scene Filters, Copy and Paste Filters, Screenshot Scene, and Transition Override..., which picks a specific transition for switching to that scene.

When the live scene changes, MetaOBS announces "Live:" followed by its name. With a transition it announces "Transition from A to B".

6. Sources panel

The panel is named "Sources in" followed by the scene name. In Studio Mode it shows the preview scene. It is a tree: open and close groups with the Right and Left Arrow keys. Each source says whether it is hidden or locked. Use Ctrl or Shift to select several sources.

7. Layout mode

Layout mode lets you place a source in the scene without a mouse. Select a source in the Sources panel and press Ctrl+M. MetaOBS announces the source and the current step; from then on, keys act on the source:

Layout mode keys
KeyAction
ArrowsMove the source
Ctrl+arrowsChange the width (Right, Left) or height (Down, Up)
+ and -Grow or shrink, keeping the proportions
Alt+arrowsCrop that side
Alt+Shift+arrowsReduce the crop of that side

The description gives the position, size, area of the scene (for example "top right"), how much of the scene the source covers, any crop, and which other sources cover it or are covered by it. You get the same description outside layout mode with Describe Position in the Source menu.

Ctrl+Z undoes changes; a burst of key presses counts as a single change.

8. Webcam framing check

MetaOBS can tell you whether your face is centered in the webcam picture. It uses the face detection built into Windows; images never leave your computer.

Single check

Select the webcam in the Sources panel and press Ctrl+Shift+F. MetaOBS speaks one sentence, such as "Face centered", "move a little to your left, face a little high" or "You are far away: come closer". It also reports a black picture (the webcam may be covered, off or in use by another program), a very dark or very bright picture, no face, or several faces (the advice is then about the closest one).

Left and right advice is an instruction from your point of view ("move to your right"). Height advice describes where your face is ("face too low"): fix it by raising or lowering the webcam or yourself.

Continuous guidance

Ctrl+Alt+F turns on framing guidance: MetaOBS announces every change while you adjust your position, until you press Ctrl+Alt+F again. It turns itself off after two minutes.

The part shown in the scene

The advice is about the part of the webcam picture that the scene shows, taking crop, size and position into account. If your face is outside that part, or cut off, MetaOBS says so.

Mirrored picture

Some webcams or their drivers mirror the picture, which would swap left and right. To fix this once and for all, select the webcam and choose Calibrate Left and Right... from the Source menu. Look at the webcam and keep still, then, when asked, move or lean to your right. MetaOBS sets Mirrored Camera Picture for you; you can also check it by hand.

From any program

In Settings, Hotkeys you can assign global keys to "Screen reader: Check Framing" and "Screen reader: Framing Guidance". They use the webcam you checked last or, if there is none, the first visible webcam in the live scene.

10. Controls panel and transitions

The first row of the panel holds the buttons: Start or Stop Streaming, Start or Stop Recording, Pause Recording, Start Replay Buffer, Save Replay, Start Virtual Camera, Configure Virtual Camera and Studio Mode. Only the buttons that make sense with your current settings appear; Pause Recording, for example, appears while recording.

The second row holds the current transition (a combo box) and its duration in milliseconds. In Studio Mode there are also the Transition button, which sends the preview scene live, and the manual transition (T-bar): a percentage slider you move with the arrow keys. At 100 it completes the transition; back at 0 it cancels it.

The Controls menu has the same actions, plus:

  • Quick Transitions, to run a transition right away with another duration;
  • Scene Transitions, to pick, add, rename, configure or remove transitions.

Studio Mode

In Studio Mode you prepare a scene in the preview without your audience seeing it. In the Scenes panel, Enter puts a scene in the preview, and the Sources panel shows the preview's sources. Then the Transition button, or Ctrl+Enter in the Scenes panel, sends it live.

11. Status panel and warnings

The Status panel is a list that updates itself. It contains:

  • streaming state and duration, bitrate and frames dropped by the network;
  • recording state and duration;
  • replay buffer and virtual camera;
  • CPU usage and frames per second;
  • frames missed due to rendering lag or skipped due to encoding lag;
  • free disk space;
  • the last status bar message.

The Status menu reads this information without moving the focus: summary, streaming, recording, performance, disk space, current scene and last message. Each of these readouts can be assigned to a global hotkey (see section 13).

Warnings

If the share of frames lost in the last 10 seconds reaches the threshold (5% unless you change it), MetaOBS warns you, at most once a minute. While recording, it also warns when less than 5 GB, and then less than 1 GB, of disk space is left. If the connection drops, it announces in how many seconds it will try to reconnect.

13. Global hotkeys

Global hotkeys work even when MetaOBS is not in the foreground. Assign them in File, Settings, Hotkeys: type the action's name in the filter field, move to its key field and press the keys you want.

Besides the usual OBS actions (start and stop streaming and recording, switch scene, mute a source, show or hide a source and so on), MetaOBS adds these actions, whose names start with "Screen reader:":

  • Read Status Summary
  • Read Streaming Status
  • Read Recording Status
  • Read Performance
  • Read Disk Space
  • Read Current Scene
  • Read Last Message
  • Switch between Accessible Mode and the standard interface
  • Check Framing
  • Framing Guidance

None of them has keys assigned at first. Pick combinations that you don't use in other programs, for example with Ctrl+Alt+Shift.

14. Command palette

Ctrl+Shift+P (or View, Command Palette) opens a search over every menu command. Type part of a name, such as "record" or "filters", and MetaOBS says how many commands it found. Enter runs the first one; Down Arrow moves to the result list, where each command shows its menu and its shortcut. It is also a good way to learn the shortcuts.

15. Dialogs, filters and docks

MetaOBS has also made the dialogs it shares with OBS Studio accessible: source properties, filters, hotkeys, add source, edit transform, advanced audio properties and settings.

Filters

The Filters dialog has two lists: audio filters and video effects. Each filter says whether it is enabled or disabled; the "Enabled" check box turns it on and off. The selected filter's settings follow the list in the Tab order.

Interact

In the Interact dialog, keys are sent to the source (for example to a web page). To get out, press Ctrl+Tab to reach the Close button, or Shift+Esc to close the dialog.

Plugin docks

Many plugins add panels ("docks"). In Accessible Mode you find them in View, Plugin Docks...: choose a dock and press Open to show it as a separate window, or Hide. From there you also reach Custom Browser Docks, which show a web page in a panel. To remove one, move to its delete button and press Delete, or press Ctrl+Shift+Delete in one of its fields.

When you close a dock, OBS may suggest reopening it from the Docks menu. In Accessible Mode, use View, Plugin Docks instead.

Windows of external plugins

Some plugins, such as audio plugin hosts, show a window of another program inside their panel. When the focus reaches that window, MetaOBS hands it to the window's contents; Ctrl+Tab and Ctrl+Shift+Tab bring you back to the MetaOBS controls. How accessible the contents are depends on the plugin.

16. Stream Deck

MetaOBS drives Elgato Stream Decks directly, without the Elgato Stream Deck app (which is not accessible). Connect the Stream Deck and open Tools, Stream Deck....

Close the Elgato Stream Deck app: if it is running, it would also run its own actions, and the MetaOBS dialog warns you about it. Support has been tested with the Stream Deck Mini MK.2; the Mini, MK.2 and XL are also supported.

The Stream Deck dialog

  • Status: which Stream Deck is connected.
  • Use the Stream Deck in MetaOBS: turns everything on or off.
  • Keys (press a key on the Stream Deck to find it): a list with one row per key, for example "Key 1, top left: Start Recording". While the dialog is open, pressing a physical key does not run its action; it selects the key's row. That is the easiest way to find a key.
  • Assign action...: opens the list of all actions, grouped as General, Scenes, Sources, Outputs and so on, with a search field. For paired actions (start and stop recording, mute and unmute), the Toggle with ...: one key for both check box makes one key do both.
  • Label on the key: the text shown on the key's display.
  • Remove action, and Try, which runs the selected key's action.
  • Announce what each key does and Key brightness.

When you press a key, MetaOBS interrupts speech and announces the result, for example "Mic/Aux muted" or "Webcam shown". Streaming, recording and scene changes use the usual announcements. A key assigned to push-to-talk stays active as long as you hold it.

The display shows the key's label in white, or in gray when the action is not available (for example, its source was deleted). MetaOBS announces when a Stream Deck is connected or disconnected.

17. MIDI controllers

You can control MetaOBS with a MIDI controller: knobs and faders for volume, balance, the T-bar, the transition duration and filter settings; buttons for mute, scenes, streaming, recording and any other action. If the controller has lights or motorized faders, MetaOBS sends the state back to it.

Assigning a control (MIDI learn)

  1. Move the focus to what you want to control: a mixer row, a scene, the T-bar, the duration, a button in the Controls panel, a setting in a source's or filter's properties, a control in the audio properties.
  2. Press Ctrl+Shift+M. MetaOBS says what it is waiting for, for example "move a knob or fader for Mic/Aux: volume, or press a button for Mic/Aux: mute", and what it is assigned to now.
  3. Move the knob or fader, or press the button, on the controller. MetaOBS confirms the assignment.

While it waits, Esc cancels and Delete removes the existing assignment. Endless encoders are recognized automatically.

With a non-motorized fader, if the value in MetaOBS differs from the fader's position, the fader has no effect until it reaches that value, so the volume never jumps. MetaOBS guides you with "Move up to reach..." or "Move down to reach...".

The MIDI Controllers dialog

Open it from Tools, MIDI Controllers.... It contains:

  • Use MIDI controllers in MetaOBS.
  • Input ports: the controllers found; Space turns each one on or off.
  • Output port for lights and motorized faders: "Automatic" picks the one with the same name as the input.
  • Assignments: the list of assignments. Moving a control on the controller selects its row or, if the control is free, adds a new one.
  • Assign action...: for buttons, picks an action from the full list, as for the Stream Deck.
  • Options...: control type (knob or fader, or a kind of endless encoder), soft takeover, invert direction, minimum and maximum value, sending the state to the controller, and the values for light on and off.
  • Remove assignment and Announce values and actions.

If another program is already using the controller's port, MetaOBS says so in the Status.

19. Troubleshooting

I don't hear announcements while MetaOBS is in the background.
With NVDA, check in Settings, Accessibility that Speech output is "Automatic" and that the text below it says NVDA is running, then use "Test announcement in 5 seconds". With other screen readers, background announcements are not guaranteed.
I don't hear any announcements.
Check that Announcements is not set to "Off".
The Stream Deck doesn't respond, or runs unexpected actions.
Close the Elgato Stream Deck app and check that "Use the Stream Deck in MetaOBS" is on.
The MIDI controller isn't found, or is "used by another program".
Close other music programs that use the controller and reopen the MIDI Controllers dialog.
The framing check says "Black picture".
The webcam may be covered, off or in use by another program, such as a video call app.
Left and right are swapped in the framing advice.
Use Calibrate Left and Right in the Source menu (section 8).
The update failed.
The message shown at startup names the file with the details. You can always download and install the new version by hand from the releases page.
I need to send a bug report.
From Help, Log Files, you can upload or open the log of the last session. Logs are in %APPDATA%\obs-studio\logs.
